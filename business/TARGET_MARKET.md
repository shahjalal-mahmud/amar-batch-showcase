# TARGET MARKET — Amar Batch

## 🎯 Overview

Amar Batch is built specifically for the **private tuition ecosystem of Bangladesh**.

The product targets teachers who manage students, attendance, fees, and exams manually using notebooks, diaries, spreadsheets, or memory. The goal is to replace paper-based management with a simple offline-first mobile solution that requires almost no technical knowledge.

This document defines the exact audience Amar Batch is designed for, who it prioritizes, and who it intentionally does not target.

---

# 1. PRIMARY TARGET MARKET

## 👨‍🏫 Individual Private Teachers (Core Market)

This is the main audience Amar Batch is designed for.

### Who They Are

Teachers who:
- Run private tuition batches from home
- Teach students in small coaching groups
- Take freelance tutoring classes
- Teach one or multiple academic subjects
- Manage students personally without assistants

### Typical Profile

| Category        | Details                                           |
| --------------- | ------------------------------------------------- |
| Age Range       | 20–50                                             |
| Location        | Bangladesh (urban + semi-urban)                   |
| Technical Skill | Basic smartphone users                            |
| Device          | Low to mid-range Android phones                   |
| Internet Access | Unstable or limited                               |
| Teaching Style  | Home batches, coaching, tuition                   |
| Student Count   | 10–1500 students                                  |
| Subjects        | English, Math, Science, ICT, Admission prep, etc. |

### Their Daily Problems

- Forgetting attendance
- Losing fee records
- Manual bookkeeping in notebooks
- Difficulty tracking exam performance
- Parent communication inconsistency
- Data loss from damaged notebooks
- Stress managing multiple batches

### Why Amar Batch Fits Them

Amar Batch is:
- Offline-first
- Extremely simple
- Fast to use daily
- Mobile-only
- Designed around real teacher workflows
- Affordable for Bangladeshi teachers
