# Amar Batch — Competitor Analysis

## 📊 Overview

This document analyzes the competitive landscape surrounding Amar Batch.

The purpose is to understand:

- Existing alternatives teachers currently use
- Strengths and weaknesses of competing solutions
- Market gaps Amar Batch can fill
- Why Amar Batch is positioned differently

This analysis focuses specifically on the Bangladeshi private tuition ecosystem, not the global EdTech enterprise market.

---

# 1. MARKET REALITY

## The Current Situation

Most private teachers in Bangladesh still manage everything manually using:

- Paper notebooks
- Diaries
- Excel sheets
- Facebook Messenger
- WhatsApp
- Memory

Very few teachers currently use dedicated management software.

This creates a large underserved market.

---

The competitors of Amar Batch are not only software products.

Competition comes from four main categories:

| Category                   | Examples              |
| -------------------------- | --------------------- |
| Manual systems             | Notebooks, diaries    |
| Generic tools              | Excel, Google Sheets  |
| School management software | ERP systems           |
| Coaching management apps   | Tuition/coaching apps |

# 7. COMPETITIVE DIFFERENTIATORS

## 🎯 What Makes Amar Batch Different

---

## 1. Offline-First Architecture

### Why It Matters

Many teachers:

- Have unstable internet
- Use low-end Android devices
- Prefer reliability over cloud complexity

### Competitive Advantage

Amar Batch works fully offline:

- Attendance
- Fees
- Exams
- SMS
- History
- Reports

Internet is optional.

---

## 2. Built Specifically for Bangladeshi Teachers

Most competitors are:

- Generic
- International
- Institution-focused

Amar Batch is localized around:

- Tuition culture
- Parent communication style
- bKash/Nagad payments
- Android-first usage
- Low-tech teacher workflows

---

## 3. Simplicity as a Feature

Many competitors add:

- Analytics dashboards
- Complex reporting
- Multi-role systems
- Unnecessary automation

Amar Batch intentionally stays simple.

### Product Philosophy

> "Open → Mark → Save → Done."

---

## 4. SMS Using Teacher's Own SIM

This is one of Amar Batch's strongest differentiators.

### Why It Matters

Most competitors:

- Require internet SMS gateways
- Charge per SMS
- Depend on cloud services

Amar Batch:

- Uses teacher's own SIM
- Works offline
- Keeps teacher in control
- Has no SMS infrastructure cost

# 15. FINAL STRATEGIC INSIGHT

The biggest competitor is not another app.

The biggest competitor is:

- Habit
- Paper notebooks
- Manual workflows
- Resistance to change

This means Amar Batch succeeds only if it feels:

- Easier than notebooks
- Faster than manual tracking
- More trustworthy than memory
- Simple enough to use every day

# Final Statement

Amar Batch occupies a unique position in the Bangladeshi EdTech ecosystem:

> It is not a school ERP.
> It is not a complicated SaaS dashboard.
> It is not a generic attendance tool.

It is a focused productivity tool built specifically for Bangladeshi private teachers who need simplicity, reliability, and organization in their daily teaching workflow.

The competitive advantage of Amar Batch is not feature quantity.

Its advantage is understanding the real-life behavior and needs of private teachers better than generic software solutions.
