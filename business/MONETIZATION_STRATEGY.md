## Free Trial Strategy

### Trial Duration

| Period    | Action                           |
| --------- | -------------------------------- |
| Day 1-60  | Full access, no restrictions     |
| Day 55    | Reminder: "5 days left in trial" |
| Day 60    | Trial ends, license required     |
| Day 61-63 | Grace period (3 days)            |
| Day 64    | Access blocked until payment     |

### Why 60 Days?

- Teachers need time to experience real value
- One full academic term (Jan-March or July-September)
- Enough to see attendance + fees + exam benefits
- Not so long that teachers delay purchase decision

### Trial Features

| Feature            | Trial Access   |
| ------------------ | -------------- |
| All core features  | ✅ Full access |
| Student management | ✅ Unlimited   |
| Attendance         | ✅ Unlimited   |
| Fee tracking       | ✅ Unlimited   |
| Exam tracking      | ✅ Unlimited   |
| SMS system         | ✅ Unlimited   |
| Backup/Restore     | ✅ Unlimited   |

**No feature restrictions during trial.** Teachers experience the complete product.

## Payment Process

### Current (Manual)

1. Teacher installs app (APK from website/Play Store)
2. Free trial starts automatically
3. Teacher uses app for 30-60 days
4. Teacher contacts developer: mahmud.nubtk@gmail.com
5. Teacher pays via bKash or Nagad
6. Developer verifies payment
7. Developer activates license via admin panel
8. Teacher continues using app for 1 year

## Monetization Principles

### What We Charge For

| Item                                    | Charged?                    |
| --------------------------------------- | --------------------------- |
| App download                            | No (free trial)             |
| Core features (attendance, fees, exams) | Yes (after trial)           |
| SMS system                              | No (teacher pays SIM)       |
| Backup                                  | No (teacher's Google Drive) |
| Updates                                 | No (included in license)    |
| Support                                 | No (included)               |

### What We Don't Charge For

- ❌ Per-student pricing
- ❌ Per-SMS fees
- ❌ Storage fees
- ❌ Feature tiers
- ❌ Hidden charges
- ❌ Auto-renewal surprises

### What We Never Do

| Practice     | Why Not                  |
| ------------ | ------------------------ |
| Ads          | Distracting for teachers |
| Data selling | Privacy violation        |
| Upselling    | One simple product       |
| Hidden fees  | Trust is essential       |
