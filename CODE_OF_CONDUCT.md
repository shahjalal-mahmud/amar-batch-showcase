# Code of Conduct

## Our Pledge

In the interest of fostering an open and welcoming environment, we as maintainers of **Amar Batch** pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

**Important Note:** Amar Batch is a **proprietary commercial application**, not an open-source project. This repository exists for documentation, issue tracking, feedback, and public visibility. The source code is not licensed for modification, redistribution, or unauthorized use.

We are building a tool for Bangladeshi teachers. Our community must reflect the same respect and trust that teachers deserve in their classrooms.

---

## Our Standards

### ✅ Behavior That Makes This Community Better

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the project and its users (the teachers!)
- Showing empathy toward other community members
- Acknowledging when you don't know something — we all start somewhere
- Reporting bugs, suggesting features, and providing honest feedback

### ❌ Behavior That Is Not Acceptable

- The use of sexualized language or imagery, or unwelcome sexual attention
- Trolling, insulting or derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing others' private information (email, phone number, address) without explicit permission
- Dismissing or mocking feedback from teachers or beta testers who may not be technical
- Spam, off-topic self-promotion, or irrelevant content in issues and discussions
- Requesting or attempting to access proprietary source code
- Reverse engineering, decompiling, or attempting to extract the application's source code
- Distributing modified or cracked versions of the application
- Any other conduct which could reasonably be considered inappropriate in a professional setting

---

## Responsibilities

**Project maintainer (MD Shahajalal Mahmud)** is responsible for clarifying the standards of acceptable behavior and is expected to take appropriate and fair corrective action in response to any instances of unacceptable behavior.

The maintainer has the right and responsibility to remove, edit, or reject comments, issues, and other contributions that are not aligned with this Code of Conduct, or to temporarily or permanently ban any contributor for other behaviors deemed inappropriate, threatening, offensive, or harmful.

---

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub Issues, Pull Requests (if enabled), and Discussions
- The project repository (comments, code reviews, documentation feedback)
- Direct messages sent in the context of this project
- Any community spaces created for Amar Batch (e.g., WhatsApp groups, Facebook groups)

This Code of Conduct also applies when an individual is officially representing the project in public spaces.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior will be reviewed and investigated. The maintainer will respond in a way that is deemed appropriate to the circumstances. This may include:

1. **Warning** — A private written warning explaining the violation and expected change in behavior.
2. **Temporary Suspension** — A temporary ban from interacting with the project community.
3. **Permanent Ban** — A permanent ban from any future interaction with the project.

Maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project's leadership.

---

## A Note on Feedback from Teachers

Amar Batch is built _for_ teachers. Beta testers and users who are not developers are a core part of this community. Please treat their feedback — even if informal, written in Bangla, or technically imprecise — with the same respect as expert technical input. Their lived experience is the most valuable contribution of all.
