# Installation Guide — Amar Batch

> Currently distributed as a manual APK. Play Store release is in progress.

---

## Requirements

| Item            | Requirement                      |
| --------------- | -------------------------------- |
| Android version | 8.0 (Oreo) or higher             |
| Storage         | ~50 MB free                      |
| Google account  | Required for backup and sign-in  |
| SIM card        | Required for SMS features        |
| Internet        | Only for backup and license sync |

---

## Install the APK

**Step 1 — Download the APK**

Get the latest APK from the live product page:
[appriyo.com/app/amarbatch](https://appriyo.com/app/amarbatch)

Or contact the developer directly for the APK file:
**Email:** mahmud.nubtk@gmail.com

---

**Step 2 — Allow installation from unknown sources**

Since this is a manual APK (not from the Play Store), you need to allow your phone to install it.

On Android 8.0 and above:

- Open the APK file after downloading
- Your phone will ask for permission to install
- Tap **Settings** → enable **Allow from this source** → go back and tap **Install**

On older Android versions:

- Go to **Phone Settings → Security → Unknown Sources** → enable it

---

**Step 3 — Install and open**

Tap **Install** → wait for installation to finish → tap **Open**.

---

## First-Time Setup

Once the app opens, complete the one-time setup:

1. Choose **New User** (first time) or **Existing User** (reinstall / new phone)
2. Sign in with your Google account
3. Enter your name, phone number, and batch name
4. Tap **Start**

Full setup takes under 2 minutes.

For a detailed walkthrough, see the [Getting Started Guide](../user_guide/getting_started.md).

## Required Permissions

The app will ask for the following permissions:

| Permission           | Why it's needed                                            |
| -------------------- | ---------------------------------------------------------- |
| **Send SMS**         | To send attendance, fee, and exam notifications to parents |
| **Read Phone State** | To detect which SIM to use on dual-SIM phones              |
| **Internet**         | For Google Drive backup and license validation             |
| **Google Account**   | For sign-in and Drive backup                               |

All permissions can be managed from **Phone Settings → Apps → Amar Batch → Permissions**.

If you deny SMS permission, the SMS features will not work. All other features remain fully functional.

## Updating the App

When a new version is available:

1. Download the new APK from the same link
2. Install it over the existing app — your data is not affected
3. The app will migrate any database changes automatically

---

## Uninstalling

If you uninstall the app, your local data will be deleted from the phone. If you had Google Drive backup enabled, your data is safe and can be restored when you reinstall.

**Before uninstalling, take a manual backup:**
Settings → Backup & Restore → Backup Now

---

## Troubleshooting Installation

**"App not installed" error:**

- Make sure your Android version is 8.0 or higher
- Clear some storage space if your phone is nearly full
- Try downloading the APK again (the file may be incomplete)

**App crashes immediately after opening:**

- Restart your phone and try again
- Clear the app cache: Phone Settings → Apps → Amar Batch → Storage → Clear Cache

**SMS not working after install:**

- Go to Phone Settings → Apps → Amar Batch → Permissions → enable SMS permission
- Check that your SIM has balance
