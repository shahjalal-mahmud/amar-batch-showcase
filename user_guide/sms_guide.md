# SMS গাইড — আমার ব্যাচ

> আপনার নিজের সিম থেকে অভিভাবকদের কাছে সরাসরি SMS পাঠান।

---

## SMS কীভাবে কাজ করে

- SMS আপনার ফোনের সিম থেকে যায়। আলাদা কোনো সার্ভিস বা ইন্টারনেট লাগে না।
- অভিভাবক দেখবেন SMS এসেছে আপনার নম্বর থেকে।
- সাধারণ SMS চার্জ কাটবে আপনার সিম ব্যালেন্স থেকে।
- ব্যাকগ্রাউন্ডে একটি একটি করে SMS পাঠানো হয়। তাই আপনাকে অপেক্ষা করতে হবে না।

---

## প্রথমবার SMS চালু করুন

**ধাপ ১ —** Settings বা More ট্যাবে যান → SMS Settings এ যান

**ধাপ ২ —** "Enable SMS" টগল চালু করুন

**ধাপ ৩ —** যদি দুটো সিম থাকে — কোন সিম থেকে SMS যাবে তা বেছে নিন (SIM 1 বা SIM 2)

**ধাপ ৪ —** Save করুন

---

## ক্লাস অনুযায়ী SMS নিয়ন্ত্রণ করুন

আপনি চাইলে এক ক্লাসে SMS চালু রাখতে পারেন, অন্য ক্লাসে বন্ধ রাখতে পারেন।

Classes ট্যাবে যান → ক্লাসের নামে চাপ দিন → SMS Settings এ যান → কোন ধরনের SMS চালু রাখবেন বেছে নিন।

---

## কোন কোন SMS পাঠানো যায়

| SMS-এর ধরন                 | কখন যাবে             |
| -------------------------- | -------------------- |
| ভর্তির স্বাগত বার্তা       | নতুন ছাত্র ভর্তি হলে |
| অনুপস্থিতির বার্তা         | ছাত্র ক্লাসে না এলে  |
| বেতন পরিশোধের রসিদ         | বেতন নেওয়ার পর      |
| বেতন বাকির রিমাইন্ডার      | শিক্ষক পাঠালে        |
| পরীক্ষার ফলাফল             | নম্বর দেওয়ার পর     |
| মাসিক উপস্থিতির সারসংক্ষেপ | শিক্ষক পাঠালে        |

প্রতিটি আলাদাভাবে চালু বা বন্ধ করা যায়।

---

## বেতনের রিমাইন্ডার পাঠান

**একজনকে:**
Fees ট্যাবে যান → বকেয়া ছাত্রের পাশে SMS আইকনে চাপ দিন → মেসেজ দেখুন → Send করুন।

**সবাইকে একসাথে:**
SMS Actions অপশনে যান → Fee Reminder বেছে নিন → ক্লাস বেছে নিন → Send করুন।

---

## মাসিক উপস্থিতির সারসংক্ষেপ পাঠান

মাস শেষে সব অভিভাবককে তাদের সন্তানের উপস্থিতির হিসাব জানাতে:

SMS Actions অপশনে যান → Attendance Summary বেছে নিন → ক্লাস ও মাস বেছে নিন → Send করুন।

---

## SMS-এর ভাষা পরিবর্তন করুন

অ্যাপে ডিফল্ট মেসেজ ইংরেজিতে আছে। বাংলায় বা নিজের ভাষায় লিখতে পারেন।

Settings → SMS Templates এ যান → যে মেসেজটি পরিবর্তন করতে চান সেটিতে চাপ দিন → নিজের ভাষায় লিখুন → Save করুন।

**মেসেজে ব্যবহারযোগ্য চিহ্ন:**

| চিহ্ন          | অর্থ           |
| -------------- | -------------- |
| {student_name} | ছাত্রের নাম    |
| {month}        | মাসের নাম      |
| {amount}       | টাকার পরিমাণ   |
| {teacher_name} | আপনার নাম      |
| {date}         | তারিখ          |
| {mark}         | পরীক্ষার নম্বর |

**উদাহরণ:**

```
প্রিয় অভিভাবক, {student_name} আজ ({date}) অনুপস্থিত ছিল। — {teacher_name}
```

---

## SMS কিউ দেখুন

কোন SMS পাঠানো হয়েছে, কোনটা এখনো বাকি, কোনটা ব্যর্থ হয়েছে তা দেখতে:

Settings বা More → SMS Queue অপশনে যান।

ব্যর্থ SMS সর্বোচ্চ ৩ বার চেষ্টা করা হয়। তারপর Failed হিসেবে চিহ্নিত হয়।

---

## সাধারণ সমস্যা

**SMS যাচ্ছে না?**

- ফোনের Settings → Apps → Amar Batch → Permissions → SMS permission চালু আছে কিনা দেখুন
- সিমে ব্যালেন্স আছে কিনা চেক করুন
- Airplane Mode বন্ধ আছে কিনা দেখুন

**SMS দেরিতে যাচ্ছে?**
SMS একটি একটি করে ৯ সেকেন্ড বিরতিতে পাঠানো হয়। ৩০ জনের SMS পাঠাতে প্রায় ৫ মিনিট লাগতে পারে।

**অভিভাবক বলছেন SMS আসেনি?**
ছাত্রের প্রোফাইলে যান এবং অভিভাবকের নম্বরটি সঠিক আছে কিনা দেখুন।
